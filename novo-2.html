Agora, uma página muito mais agradável e legível é exibida. Para isso, tivemos que adicionar as marcações que são pertecentes ao HTML. Essas marcações são chamadas de TAGS, e elas basicamente dão uma representação ao texto contido entre sua abertura e fechamento.

Apesar de estarem corretamente marcadas, as informções não apresentam pouco ou nenhum atrativo estético e, nessa deviciência do HTML, reside o primeiro e maior dasafio de pessoas que desenvolvem para front-end.

O HTML (Hypertext Markup Language) ou linguagem de marcação de hipertexto foi desenvolvido para suprir a necessidade exibição de documentos científicos fornecidos por uma rede de Internet. Para termos uma comparação, é como se a Web fosse desenvolvida para exibir monografias redigidas e formatadas pela Metodologia do TRABALHO CIENTÍFICO da ABNT. Porém, com o tempo e a evoluçãoda Web e de seu potencial, comercial, tornou-se necessária a exibição de informações com grande riqueza de elementos gráficos e de interações.

3.2 SINTAXE DO HTML O HTML é um conjunto de tags responsáveis pela marcação do conteúdo de uma página no navegador. No código que vimos antes, as tags são os elementos a mais que escrevemos usando a sintaxe . Diversas tags são disponibilizadas pela linguagem HTML e cada uma possui uma funcionidade específica.
