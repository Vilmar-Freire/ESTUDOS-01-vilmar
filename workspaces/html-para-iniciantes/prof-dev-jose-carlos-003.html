No HTML, a tag "SPAN" é um elemento inline genérico usado para agrupar e aplicar estilos ou comportamentos a uma parte específica do texto ou conteúdo sem criar uma quebra de linha. Principais características: Inline: não inicia uma nova linha, diferente de elementos de bloco como "div". Sem significado semântico: por si só, não altera o conteúdo nem indica um significado especial. Usado para estilização ou scripts: geralmente combinado com CSS ou JavaScript.

Qual a função do display block NO HTML: A função principal do display: block é fazer com que um elemento HTML ocupe 100% da largura disponível de seu contêiner e inicie sempre em uma nova linha. Isso significa que nenhum outro elemento ficará ao lado dele por padrão. Mais se eu quiser eu poço usar o 'hr' para quebrar linha pois ele é um displei block. Posso também usar o 'br' mais ele não segue a linha divisória.
